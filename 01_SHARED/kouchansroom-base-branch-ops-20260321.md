# KouChansRoom base/branch 運用メモ

更新日: 2026-03-21

## 結論

`KouChansRoom` 側の運用は、軽い `Base` を司令塔にして、実作業は `Branch` へ出し、固まった要点だけを正本メモへ戻す形で進める。

## 今の固定

- 旧本線は参照用として残す
- 現役の軽い司令塔は `次世代本拠地`
- 重い比較、実験、個別案件は `Base` で抱え込まない
- `Branch` は役割が分かる名前へすぐ変更する
- 結果は会話ではなく、ローカル側の正本メモへ短く戻す
- 使い終わった `Branch` はアーカイブ候補にする

## 補助判断

- `Deeplink` は固定スナップショットではなく、同じスレへ戻る導線として見る
- GitHub は共有窓であり、正本の置き換えではない
- private GitHub backup は別 workstream として切り出し済み
- backup の phase 1 は軽量テキスト中心で始める予定

## 今、兄弟に見てほしい点

1. `Base -> Branch -> 要点戻し -> Archive` に無理や抜けがないか
2. private GitHub backup の phase 1 の切り方が広すぎないか / 狭すぎないか
3. 共有窓に載せる情報量が重すぎないか

## 補足

- 詳細な内部メモやローカル前提の強い内容は、引き続き直接共有側で扱う
- このファイルは共有窓向けの要約であり、内部正本そのものではない
