# 入院前の止めどころメモ

更新日: 2026-03-16

## 結論

現時点で、入院前の最低限ラインはかなり満たせている。

今日の主案は、まず兄弟と共有して、

- `A. ここで止める`
- `B. 外部WOLを軽く試す`

のどちらにするかを決めること。

## ここまでで確認できたこと

- `Sunshine` は起動済みで Web UI に入れる
- `Moonlight` は同一LANで `Desktop` 接続まで確認済み
- `scrcpy` は USB デバッグ再許可で再接続済み
- GitHub 共有窓は更新済み
- GitHub 専用プロフィールは作成・ショートカット化・起動確認まで完了
- `povo` の物理SIMは申込完了、到着待ち

## 外部WOLの現在地

- Windows 側の前提はかなり良い
  - 有線LAN
  - `Intel(R) Ethernet Connection (17) I219-V`
  - `Wake on Magic Packet = Enabled`
- ルーター側の前提もかなり良い
  - `Huawei HG8045Q`
  - グローバルIPv4あり
  - `DHCPスタティックIP設定`
  - `ARP設定`
  - `ポートマッピング設定`
  が見えている

ただし、まだ

- BIOS / UEFI 側の確認
- DHCP固定
- ARP
- ポートマッピング
- 外部からの実地起動確認

は未実施。

## 現実案

### A. 今日の本命

- `画面オフ`
- `本体スリープなし`

WOL は今回は保留。
現時点で一番安全。

### B. 妥協案

- `本体スリープを 2〜3時間`
- 落ちたら家の人に起こしてもらう

外部WOLを組まなくても成立しやすい。

### C. 余力があれば試す案

- `DHCPスタティックIP設定`
- `ARP設定`
- `UDPポートマッピング`

を入れて、外部WOLを実地テストする。

技術的には狙える構成だが、まだ未設定・未検証。

## 今日ここで相談したいこと

- 今回は `A` で止めるのが自然か
- それとも `C` を軽く試す価値があるか
- 試す場合、入院前の優先順位として見合うか

## 補足

今回の土台としては、

- GitHub 共有窓で病院中も軽い運用は継続しやすい
- `Moonlight` が通れば実機作業もできる
- `Moonlight` が通らなくても、全部が止まるわけではない

という状態まで来ている。
