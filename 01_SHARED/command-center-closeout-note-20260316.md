# COMMAND_CENTER運用再編の締めメモ

更新日: 2026-03-16

## 今回の締め方

今回は、`COMMAND_CENTER運用再編` という現行名のままで締める。
ここで無理に案件名を巻き戻して変えない。

参照欄には、最新の統合ZIPだけを残す。
ZIP は、今回案件の `アーカイブ / 締め記録` として扱う。

次に動くための整理材料は、private 側の md を入口にする。

## 今回の最終判断

- 入院中の本線は `GitHub共有窓 + ブラウザ運用`
- `Sunshine / Moonlight` は条件が良い時だけ使う保険枠
- `外部WOL` は今回は保留
- `COMMAND_CENTER` 側は運用判断までで一区切り
- 次は `Android / ブラウザ案件` を別プロジェクトで進める

## 役割の整理

- 最新の統合ZIP = 今回案件の固定スナップショット
- private 側の md = 次に動くための正本入口
- GitHub共有窓 = 共有用の軽量入口

## 次回からの命名ルール

次の別プロジェクトから、最初に英語 slug を1つ決める。

- プロジェクト名
- ZIP名
- private 側の整理 md 名

は、その slug 基準で揃える。

表示用の日本語補足は、必要な時だけ付ければよい。
今回の案件名までは巻き戻して変えない。

## 補足

今回は「名前をきれいに直すこと」より、
「現行名のままで無理なく締めること」を優先した。

その上で、次回から命名ルールを揃えることで、
過去分の巻き戻しコストを増やさずに整理を前進させる。
